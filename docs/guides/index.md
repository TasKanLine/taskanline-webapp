# 📖 Документация TasKanLine Client

## 👋 Добро пожаловать

Добро пожаловать в документацию TasKanLine Client! Это современное Angular-приложение, построенное с использованием передовых архитектурных паттернов и best practices. Наша цель - предоставить разработчикам всех уровней понятные и полные руководства для эффективной работы с проектом.

TasKanLine Client демонстрирует современный подход к разработке на Angular, используя standalone components, signals-based архитектуру и NgRx для управления состоянием. Проект спроектирован с учетом масштабируемости, поддерживаемости и отличного пользовательского опыта.

## 🎯 Быстрый старт

### 1. Клонирование и установка

```bash
git clone <repository-url>
cd TasKanLine/client
npm install  # или bun install
```

### 2. Запуск разработки

```bash
npm run s  # запуск dev сервера
```

### 3. Открытие в браузере

Перейдите на `http://localhost:4200`

## 🧭 Ключевые концепции

### 🏛️ Архитектурные принципы

- **Standalone Components** - Никаких NgModules, компоненты работают автономно
- **Signals-first** - Использование Angular Signals для реактивности
- **Feature-based структура** - Логическая группировка по функциям
- **NgRx Store** - Централизованное управление состоянием

### 🎨 Технологический стек

- **Angular 21** - Последняя версия с современными возможностями
- **TailwindCSS** - Utility-first подход к стилизации
- **TypeScript** - Строгая типизация для надежности
- **Vitest** - Быстрое тестирование

## 🛠️ Частые вопросы

### ❓ Как добавить новый компонент?

1. Создайте standalone component в соответствующей feature директории
2. Используйте `ChangeDetectionStrategy.OnPush`
3. ДобавьтеSignals для state management
4. Напишите unit тесты
5. Обновите [components-guide.md](./architecture/components-guide.md)

### ❓ Как добавить новую фичу?

1. Создайте новую директорию в `src/app/features/`
2. Реализуйте feature следуя архитектурным правилам
3. Добавьте route в `app.routes.ts`
4. Обновите NgRx store если нужно
5. Обновите документацию

### ❓ Как работать с NgRx?

Изучите [детальное руководство](./architecture/state-management.md). Основные принципы:

- Actions для описания намерений
- Reducers для pure transformations
- Effects для side effects
- Selectors для доступа к данным
