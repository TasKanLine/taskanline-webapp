# Требования: Auth UI в Header (Welcome) и Sidebar (Home)

## Цель
Сделать единый UX для авторизованных и неавторизованных пользователей на страницах **Welcome** и **Home**:
- В **Header** (Welcome) справа от theme-switcher показывать **Login/Signup** или **аватар с инициалами**.
- В **Sidebar** (Home) внизу показывать **кнопку пользователя (инициалы + username)** и **меню (Profile/Logout)**.

> ПРИМЕЧАНИЕ: Полный редизайн страницы Profile будет позже. В этой задаче — только логика и UI для Header/Sidebar.

---

## Источники данных
- Использовать NgRx selector-сигналы из `@core/auth/store/auth.reducer`:
  - `selectUser`
  - `selectIsAuthenticated`
- Локальные состояния (открытие меню) — через `signal()`.
- Для logout — `AuthActions.logout()`.

### Логика инициалов (единая для всех мест)
Использовать тот же алгоритм, что и в `Profile`:
1. Если есть `first_name` и `last_name` → первые буквы в верхнем регистре (например, `John Doe` → `JD`).
2. Если есть только `first_name` → первая буква.
3. Иначе → первые 2 символа `username`, если он есть.
4. Иначе → первые 2 символа `email`.

Рекомендуется вынести в shared-утилиту или shared-компонент, чтобы не дублировать код.

## Требования к Header (Welcome)
### Состояния
1. **Гость (не авторизован)**:
   - Справа от `app-theme-switcher` показывать кнопки **Login** и **Signup**.
   - Кнопки ведут на маршруты `/login` и `/signup`.

2. **Авторизован**:
   - Вместо Login/Signup показывать круглый аватар с инициалами.
   - Аватар — кликабельный (кнопка), открывает меню пользователя.

### Меню пользователя (Header)
- Позиция: рядом с аватаром (выпадающее меню справа).
- Пункты меню:
  - **Profile** → переход на `/profile`.
  - **Logout** → `AuthActions.logout()`.
- Закрытие меню:
  - повторный клик по аватару;
  - клик вне меню;
  - клавиша Escape.

---

## Требования к Sidebar (Home)
### Размещение
- Внизу сайдбара — отдельный блок пользователя.
- Блок всегда закреплён внизу (использовать `flex` + `mt-auto`).

### Состояния
1. **Авторизован**:
   - Кнопка пользователя с:
     - аватаром (инициалы);
     - `username` (если нет — fallback на email).
   - Клик открывает меню пользователя (Profile/Logout).

2. **Гость (не авторизован)**:
   - Блок пользователя **не отображать**.

### Меню пользователя (Sidebar)
- То же содержимое, что и в Header:
  - Profile → `/profile`
  - Logout → `AuthActions.logout()`
- Поведение по закрытию — как в Header.

---

## UI/UX требования
- Использовать Tailwind 4.1 утилиты, соблюдая текущую дизайн-систему (Flexoki, dark mode).
- Для аватара использовать те же CSS-переменные, что и в Profile:
  - `--color-initial-bg-secondary`
  - `--color-initial-text-secondary`
- Кнопки Login/Signup — через существующий `appButton`.
- Использовать современный Angular control flow (`@if`).
- Все компоненты — standalone, `ChangeDetectionStrategy.OnPush`, DI через `inject()`.
